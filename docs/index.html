02

Built to hold,
not to weigh

A stylesheet, a 120-line shell script and a launchd daemon that sleeps until something touches a protected file. That is the entire product.

01 — IDLE

Zero polling

The daemon only wakes when a protected file changes (launchd WatchPaths). At rest it costs nothing — no stutter during playback.

02 — LOCK

Immutable stylesheet

The CSS and its backup are owned by root and flagged uchg. They cannot be edited or deleted without admin rights.

03 — REPAIR

Self-healing

Turn the stylesheet off in Safari and the daemon turns it back on and restarts Safari within a second. Delete the file and it is restored from the locked backup.

04 — TIME

Firm end date

Uninstalling refuses to run before the date you chose — in the app and on the command line alike. It unlocks itself the day after.

05 — BUILD

Universal binary

One app for Apple Silicon and Intel, with no dependencies: no Homebrew, no Xcode, no Safari extension to approve.

06 — TRUST

Nothing to hide

No network calls, no logs, no telemetry. Every line that runs on your Mac is readable on GitHub before you install it.

03

Three minutes,
once

Download, drag, pick a duration. macOS asks for your admin password once — that is what installs the daemon and locks the stylesheet.

  • 1

    Download and drag to Applications

    Open the .dmg, drag YouTube Full Focus onto the Applications shortcut.

  • 2

    Allow the first launch

    The app is not notarised by Apple, so macOS blocks it the first time. See the box below — it is a one-off.

  • 3

    Pick a duration, hit Activate

    Enter your admin password so the daemon can be installed and the stylesheet locked. Safari may restart once.

⚠ “YouTube Full Focus cannot be opened”

Expected. Shipping an app without that warning requires a paid Apple Developer account. The code is fully public instead — judge it yourself.

To open it: launch the app once (the warning appears), then go to System Settings › Privacy & Security, scroll to the Security section and click Open Anyway.

One-line alternative

xattr -d com.apple.quarantine "/Applications/YouTube Full Focus.app"
04

How hard is
the block, really?

On a personal Mac, no tool can stop you forever — you are the administrator of your own machine. YouTube Full Focus does not pretend otherwise.

Guaranteed

The block survives everything you do without thinking: turning the stylesheet off in Safari, deleting the CSS file, rebooting the Mac. Each attempt is undone within a second, and uninstalling is refused before the date you chose.

Not guaranteed

With your admin password you can always unload the daemon. To close that door, browse from a standard macOS account: no sudo, no chflags, no unloading a daemon is possible there.

05

Practical
details

Does it work in Chrome, Firefox or Arc?

No. The block relies on Safari's user stylesheet, a setting specific to that browser. Other browsers are untouched — a deliberate limit, and one more argument for browsing from a standard account where you will not be installing another browser.

Why does the app ask for my admin password?

For three things: installing a LaunchDaemon in /Library/LaunchDaemons, writing the stylesheet to /usr/local/etc, and locking it with chflags uchg. Without those privileges the block would come off in one click.

Do I really have to grant Full Disk Access to /bin/bash?

Recommended, not required. Without it the CSS stays locked and active, but the daemon cannot re-tick the “user stylesheet” setting if you switch it off in Safari. The app has a button that opens the right settings pane directly.

Can I shorten the period once it has started?

No, and that is the whole point. The app only accepts a date later than the current one, and the uninstaller refuses to run before the deadline. The day after your end date, the Remove button unlocks on its own.

What happens to the videos I actually want to watch?

Nothing. Search, subscriptions, playlists, history and Watch Later all behave exactly as before, thumbnails included. The only thing you lose is the content you did not ask for — which is the content that eats the hours.
